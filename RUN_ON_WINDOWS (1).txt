OPS PILOT — WINDOWS QUICK START

1. Install Python 3.11 and enable Add Python to PATH.
2. Unzip this project and open the folder in VS Code.
3. Open Terminal > New Terminal, then run:
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python scripts\train.py
   streamlit run app\streamlit_app.py
4. Open http://localhost:8501.
5. API (second terminal): activate venv, then run:
   uvicorn api.main:app --reload
   Open http://127.0.0.1:8000/docs
6. Check quality: python scripts\evaluate.py ; pytest -q

If PowerShell blocks activation, run:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
Then activate the environment again.

LLM key is optional. Copy .env.example to .env and add GROQ_API_KEY if desired.
Never commit .env or connect this demo to production systems without security review.
